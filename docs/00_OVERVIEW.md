# 00. 서비스 개요

## 한 줄 정의

사용자가 재무조건을 선택하면 국내/미국 상장기업 전체에서 **정확히 조건을 만족하는 기업과 조건에 근접한 기업을 함께 찾아주는 재무 스크리너**.

## 서비스의 중심

실시간 트레이딩이 아니라 **기업 재무 분석과 후보 발굴**이 중심입니다.

```text
공시 재무데이터 + 일별 주가
        ↓
정규화/계산/검증
        ↓
PostgreSQL
        ↓
스크리닝 엔진
        ↓
정확 일치 + 근접 일치
        ↓
모바일/웹 관리자
```

## 사용자 검색 레벨

### 1. 일반

재무용어를 몰라도 선택 가능한 4개 전략을 시작점으로 둡니다.

- 저평가 기업
- 안정적인 기업
- 성장하는 기업
- 배당 기업

각 전략의 실제 조건은 DB의 `screen_strategy_condition`으로 관리합니다. 앱을 업데이트하지 않고 관리자가 기준을 바꿀 수 있습니다.

### 2. 고급 - 기본검색

기존 엑셀에서 사용하던 수준의 핵심 투자지표를 직접 설정합니다.

- PER / 1/PER
- PBR / PSR
- EPS 및 EPS 성장
- ROE
- 매출/영업이익/순이익 성장
- 흑자 여부
- 부채비율
- 유동비율
- 배당 관련 항목
- 과거 평균 PER 등

### 3. 고급 - 상세검색

재무상태표, 손익계산서, 현금흐름표, 성장성/수익성/안정성/가치평가 지표를 `financial_metric` 마스터에 등록하고 사용자가 직접 조합합니다.

## 가장 중요한 기능: 근접조건 검색

예:

```text
PER <= 15
ROE >= 10
```

관리자 허용오차가 PER 10%, ROE 10%라면:

- PER 14 / ROE 12 → 정확 일치
- PER 15.8 / ROE 11 → 근접 일치
- PER 14 / ROE 9.4 → 근접 일치
- PER 15.8 / ROE 9.4 → 근접 일치
- 허용범위를 더 벗어나면 제외

결과는 `EXACT`와 `NEAR`를 구분하고, 근접도 점수로 정렬합니다.

## 상업용 고려사항

- 개인정보 최소수집
- 비밀번호/Refresh Token 원문 저장 금지
- 외부 API 키는 모바일 APK에 넣지 않음
- 관리자 API 별도 권한
- 주요 변경은 감사로그
- 데이터 적재 과정은 단계별 로그
- 외부 공급자 장애 시 DB의 마지막 정상 데이터로 서비스 가능
- 광고 제거/AI 유료화는 `entitlement`로 확장
