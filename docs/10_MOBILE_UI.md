# 10. 모바일 UI 방향

## 기업 상세

- 검색 결과 카드를 누르면 기업 상세로 이동
- 회사·거래소·종목 식별정보 전체를 접이식 기본정보로 표시
- 최신 가격의 시가·고가·저가·종가·수정종가·거래량 표시
- 모든 확보 지표를 종류별로 표시
- 개요·재무제표·투자지표·배당 탭으로 구분
- 재무제표와 투자지표는 최근 4개 분기를 가로 비교표로 표시
- 표는 모바일에서 좌우 스크롤 지원
- 이력이 없으면 최신값만 표시
- 배당과 주식분할 자료가 있으면 별도 영역 표시

## 원칙

- 깔끔하고 단순
- 초보자는 재무용어 없이 시작 가능
- 고급 사용자는 한 화면에서 세밀하게 제어
- 결과에 숫자를 과하게 쌓지 않고 핵심 상태부터 표시

## 하단 메뉴 제안

```text
홈 | 고급검색 | 관심종목 | 내 설정
```

## 홈(일반)

상단:

```text
어떤 기업을 찾으세요?
```

4개 카드를 2×2 격자로 표시:

- 저평가 기업
- 안정적인 기업
- 성장하는 기업
- 배당 기업

카드 선택 → 조건 간단 설명 → 검색.

- 네이비·민트 중심 브랜드 색상
- 목적별 보조색과 의미 아이콘
- 카드 순차 등장과 눌림 반응
- 직접 조건 검색으로 이어지는 별도 행동 카드
- 하단 메뉴에 텍스트와 아이콘을 함께 표시
- 검색·약관 조회 중에는 브랜드 분석 아이콘을 이용한 로딩 상태 표시
- 관리자가 게시한 유효 기간 내 공지를 홈 상단에 표시
- 일반 전략 카드의 이름·설명·조건·노출 순서는 서버 설정을 사용하고, 연결 실패 때 초기 기본값 사용

## 고급검색

상단 Segment:

```text
[쉬운 검색] [전체 항목]
```

### 기본

- PER, ROE, PBR, EPS 성장률 기본값
- 각 지표의 정보 버튼으로 쉬운 설명 표시
- 서버가 해당 지표를 제공할 때만 최근 3년 연속 흑자와 부채비율 조건 표시

각 row:

```text
PER     [<=] [15.0]
ROE     [>=] [10.0] %
```

사용자는 허용오차를 직접 조작하지 않습니다. 근접검색은 시스템 기능으로 설명합니다.

### 전체 항목

- 서버가 반환한 모든 사용자 선택 가능 지표 표시
- 수익과 비용, 자산과 부채, 현금 흐름, 주가 수준 등 분야별 접기/펼치기
- 쉬운 검색과 같은 숫자 입력 형식
- 비워둔 항목은 검색조건에서 제외
- 예/아니오 항목은 숫자 대신 선택 버튼 사용

## 회원가입 약관

- 관리자에서 배포한 현재 버전을 DB에서 조회
- 필수/선택 구분과 전체 동의
- 제목, 본문, 버전 확인
- 가입 시 동의 여부와 실제 약관 버전 저장

## 결과

상단:

```text
정확 일치 24
근접 후보 13
```

카드:

```text
AAPL  Apple
정확 일치 · 100
PER 14.2 ✓
ROE 21.3% ✓
EPS성장 8.2% ✓
```

근접:

```text
XYZ
근접 · 92
PER 15.8  (기준 15 근접)
ROE 10.7% ✓
```

빨강/초록만으로 의미를 전달하지 않고 아이콘/텍스트 병행.

검색 결과 카드는 전체 영역을 누를 수 있습니다. 카드에는 검색에 사용한 핵심 조건만 보여주고,
선택하면 기업 상세정보로 이동합니다.

## 종목 상세

- 요약
- 가치평가
- 수익성
- 성장성
- 안정성
- 재무제표
- 현금흐름
- 배당
- 데이터 기준일

`GET /stocks/:id`가 반환한 최신 지표를 분야별 카드로 나누되 생략하지 않고 모두 표시합니다.
각 값에는 개별 기준일을 함께 표시합니다.

현재가가 EOD라면 반드시 `2026-09-04 종가 기준`처럼 날짜를 표시합니다.

## 프리셋

고급검색 조건에서 `프리셋 저장`.

```text
내 저평가 성장주
PER <= 15
ROE >= 10
EPS YoY >= 5
```
