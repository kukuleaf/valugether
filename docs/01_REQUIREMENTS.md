# 01. 요구사항 정의서

## R-001 대상 시장

- 1차: 대한민국 + 미국
- 이후: 일본/유럽 등 추가 가능
- `exchange`, `security`, `provider_security_map`으로 시장/공급자 종속 제거

## R-002 회원

필수:

- 이메일 + 비밀번호 회원가입/로그인
- 로그아웃/토큰 재발급
- 계정 상태: 정상/잠금/휴면대상/탈퇴 등 공통코드

확장:

- Google
- Kakao
- Naver

개인정보 최소화를 위해 닉네임/생년월일/성별/전화번호/주소는 서비스 필수요건이 되기 전까지 수집하지 않습니다.

## R-003 권한/수익모델

초기:

- 일반 회원 간 기능 차등 없음
- 광고 표시
- `AD_FREE` entitlement만 향후 추가 가능

향후:

- AI_BASIC
- AI_PRO
- 기타 유료 기능

회원등급 하나에 기능을 하드코딩하지 않고 `user_entitlement`로 권리를 분리합니다.

## R-004 일반 검색

- 저평가
- 안정
- 성장
- 배당

관리자 DB 조건으로 관리하며 앱 소스에 숫자를 고정하지 않습니다.

## R-005 고급 기본검색

최소 제공 지표:

- PER
- Earnings Yield(1/PER)
- PBR
- PSR
- EPS
- EPS YoY/CAGR
- ROE
- ROA
- 매출 성장
- 영업이익 성장
- 순이익 성장
- 흑자 여부/연속 흑자
- 부채비율
- 유동비율
- 영업이익률/순이익률
- FCF
- 배당수익률/배당성향
- 평균 PER

## R-006 고급 상세검색

`financial_metric.user_selectable = true`인 모든 지표를 조회해 동적으로 검색조건 UI를 구성합니다.

조건 연산자:

- <=, <, >=, >, =, BETWEEN
- 필요 시 IS_POSITIVE, CONSECUTIVE_YEARS 같은 파생지표는 서버에서 숫자/Boolean 값으로 계산

## R-007 근접검색

- 정확 조건에 미달해도 관리자 허용오차 내면 노출
- 지표별 허용오차
- 비율(PERCENT) 또는 절대값(ABSOLUTE)
- 미등록 지표는 기본 허용오차 또는 정확비교
- 지표별 가중치 가능
- 결과에 정확/근접 여부와 근접도를 표시

## R-008 프리셋

- 사용자가 고급 검색조건을 저장
- 프리셋명 수정/삭제
- 재실행
- 공개 프리셋은 향후 지원 가능

## R-009 관심종목

- 사용자별 관심종목 등록/삭제
- 메모/태그는 후속 기능으로 확장 가능

## R-010 데이터 배치

원칙:

- 사용자 요청 시 외부 데이터 공급자 호출 금지
- 시장별 하루 1회 이상 배치
- 외부 공급자 → 임시/정규화 → DB upsert
- 파생지표 재계산
- 검색용 최신값(materialized/latest table) 갱신

가격 데이터:

- 실시간 불필요
- EOD/지연 데이터면 충분
- 미국 Marketstack은 후보이며 런타임 Provider로 교체 가능

## R-011 로그

필수 로그:

- 회원가입/로그인 성공·실패/로그아웃/토큰 재발급
- 사용자 검색 조건/결과 건수/소요시간
- 프리셋/관심종목 변경
- 관리자 변경행위
- 배치 시작/종료/단계/건수/오류
- 외부 API 요청 결과(비밀키 제외)
- 데이터 insert/update/skip/error 집계
- 애플리케이션 예외

클릭/페이지 이동 전체를 무분별하게 수집하지 않습니다.

## R-012 관리자 웹

- 대시보드
- 회원 검색/상태관리
- 공통코드
- 시스템설정
- 지표 마스터
- 검색 허용오차
- 일반 전략 조건
- Provider 상태
- 배치 상태/재실행
- 로그 조회
- 공지사항

## R-013 AI 확장

v1에서 구현하지 않지만 다음 인터페이스를 염두에 둡니다.

- 종목/재무 데이터 조회 API를 AI가 재사용 가능
- 사용자 프리셋/관심종목은 AI 추천 feature로 사용 가능
- AI 생성결과/모델/프롬프트 버전/근거 데이터 시점을 별도 저장 가능
- AI 결과를 기존 deterministic screening 결과와 혼합하지 않음

## R-014 비범위

v1 제외:

- 증권계좌 연결
- 매수/매도 주문
- 자동매매
- 실시간 호가
- 틱 데이터
- 투자자문을 직접 표방하는 개인화 매수/매도 명령
