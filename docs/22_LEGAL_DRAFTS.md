# 22. 약관·개인정보·투자정보 초안

기준일: 2026-09-25

이 문서와 `database/sql/16_legal_drafts.sql`은 편집을 시작하기 위한 초안입니다. 법률 자문을
대체하지 않습니다. 운영자 형태, 실제 인프라, 광고·소셜 로그인 사용 여부와 보유기간을
확정한 뒤 전문가 검토를 거쳐 게시해야 합니다.

## 적용과 편집

```bash
npm run db:legal-drafts
```

명령 실행 후 관리자 `/terms`에 다음 `DRAFT` 문서가 생성됩니다.

- 서비스 이용약관 `2.0-draft`
- 개인정보 처리방침 및 수집·이용 동의 `2.0-draft`
- 투자정보 및 데이터 이용 안내 `2.0-draft`
- 선택 마케팅 동의 `2.0-draft`

초안은 기존 게시 약관을 바꾸지 않습니다. 관리자 화면에서 내용을 수정하고 새 정식 버전을
만든 뒤 게시합니다. `DRAFT`라는 버전명 그대로 게시하지 않습니다.

## 반드시 확정할 빈칸

- 운영자명/사업자명, 주소, 고객지원 및 개인정보 문의 이메일
- 만 14세 미만 가입 허용 여부
- 접속·감사·오류 로그 보유기간
- 회원탈퇴 웹 요청 URL
- 클라우드, DB, 로그, 오류 추적 수탁사
- Resend를 포함한 국외 이전 국가, 항목, 목적, 시점·방법, 보유기간과 거부 방법
- 약관·방침 변경 시 사전 고지기간
- 공고일과 시행일
- 광고 SDK가 실제 수집하는 광고 ID, 기기정보와 동의 방식
- Google/Kakao/Naver에서 받는 실제 항목과 연결 해제 처리

## 코드 기준 현재 처리 항목

- 이메일 또는 소셜 제공자 식별자
- Argon2id 비밀번호 해시
- 약관 버전과 동의 시각
- 관심종목, 검색 이력·프리셋, 알림 설정·내역
- refresh/인증/비밀번호 재설정 token 해시
- 요청 ID, 감사·오류·배치 기록, 해시된 IP 기반 rate-limit key
- 이메일 발송 상태

실명, 전화번호, 주소, 주민번호, 증권계좌와 투자자산 규모는 현재 수집하지 않습니다.

## 출시 전 확인 근거

- 개인정보 처리방침 공개와 정보주체 권리는 [국가법령정보센터 개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법)의 최신 조문을 기준으로 최종 검토합니다.
- Google Play는 개인정보처리방침과 Data safety 작성을 요구하며, 계정 생성 앱에는 앱 내부 삭제 경로와 웹 삭제 요청 경로가 필요합니다. [User Data 정책](https://support.google.com/googleplay/android-developer/answer/10144311), [계정 삭제 요구사항](https://support.google.com/googleplay/android-developer/answer/13327111)
- 광고·로그인 SDK를 추가한 뒤에는 해당 SDK가 수집·공유하는 항목까지 포함해 Data safety와 처리방침을 다시 대조합니다. [Data safety 작성 안내](https://support.google.com/googleplay/android-developer/answer/10787469)

## 데이터 이용조건 내부 확인

이용자 약관과 별도로 각 데이터 제공자에게 다음 사용형태를 서면 확인합니다.

- 광고가 있는 소비자 앱에서 가격·재무 데이터 표시
- 서버 DB 저장과 보유기간
- PER/PBR 등 파생지표 계산·표시
- 출처·기준일 표시 방식
- 재배포로 판단되는 범위
- 일괄 수집과 API quota

확인 답변, 계약 버전과 확인일은 `docs/16_PROVIDER_CONTRACTS.md`에 기록합니다.
